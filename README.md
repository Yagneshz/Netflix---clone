# 🎬 Netflix Clone

A responsive **Netflix landing page clone** built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Netflix's homepage while helping me strengthen my frontend development skills.

## 🚀 Features

- 🎥 Netflix-inspired modern UI
- 📱 Fully responsive design
- 🖼️ Hero section with background banner
- 📂 Movie and TV show rows
- 🎨 Smooth hover effects and animations
- 🔘 Navigation bar
- 📺 Clean layout matching the original Netflix interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
